# Checklist Design plugin for Codex

This package converts the `checklist-design` Agent Skill into a Codex plugin.

## Included

- `.codex-plugin/plugin.json` — plugin manifest
- `skills/checklist-design/SKILL.md` — skill instructions
- `skills/checklist-design/references/` — all bundled Checklist Design reference material
- `skills/checklist-design/agents/openai.yaml` — skill UI metadata

No MCP server, app connector, hook, or network dependency is required.

## Local installation

Copy the `checklist-design` directory to your Codex plugin directory (for a personal plugin, typically `~/plugins/checklist-design`). If your setup uses a marketplace file, register it there as a local plugin.
